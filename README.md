# Face tracker

A Python-based system that uses OpenCV to detect and recognize faces.

# FutureExpansions
1)Face angle tracker
2)eye tracker
3)pitch, yaw and elevation sensing


## Technologies Used
- Python
- OpenCV
- NumPy

## How to Run
1. Capture faces using `capture_faces.py`
2. Train model using `train_model.py`
3. Run attendance system using `attendance_system.py`
